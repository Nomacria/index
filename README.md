# NomaWeddings

Landing page institucional da NomaWeddings — fotografia e audiovisual para casamentos.

## Estrutura

- `index.html` — página principal
- `style.css` — identidade visual e responsividade
- `script.js` — menu mobile, scroll e animações
- `README.md` — instruções

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `nomaweddings`.
2. Envie os arquivos desta pasta para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha `main` e `/ (root)`.
6. Salve e aguarde o GitHub gerar o endereço.

## Antes de publicar

No `index.html`, altere o link do botão de WhatsApp:

`https://wa.me/5500000000000`

para o número real da NomaWeddings.

As fotos usadas atualmente são imagens remotas do Unsplash. Para um site definitivo, recomendo substituir por fotos autorais da NomaWeddings.
